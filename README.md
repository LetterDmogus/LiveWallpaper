# Mini Live Wallpaper - Portable Host & Wallpapers

> THERE MAY BE SOME PROBLEM OR FEATURE MISSING! ITS STILL ON DEVELOPMENT

### HOW TO USE:
1. Run "MiniLiveHost.exe" (The icon will appear in your System Tray near the Windows clock).
2. Right-click the tray icon -> click "Select Interactive Wallpaper (.exe)...".
3. Pick any exe file you want to use as wallpaper.
4. The interactive wallpaper is now active on your desktop!

### OR IF YOU WANT TO USE VIDEO:
1. Right-click the tray icon -> click "Select Video Wallpaper (.mp4, .mkv, .webm, etc.)...".
2. Pick any video file you want to use as wallpaper.
3. The video wallpaper is now active on your desktop!

### FEATURES:
- Interactive because it runs the exe file directly
- Automatically enters deep freeze when any Fullscreen app / Game (F11) is active for 5+ seconds.
- Memory footprint automatically trims down to only ~10 MB while active.
- Check "Start with Windows" option in the tray menu if you want the wallpaper to start automatically on boot.
- Set the preference for what condition will the wallpaper pause by itself

To close/exit: Right-click the tray icon -> click "Exit".

Currently the wrapper haven't supported multimonitor yet
